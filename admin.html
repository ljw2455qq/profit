OBS 오버레이 수익 입력

• 평소엔 일수익만 입력하면 됩니다. 하루가 지나면 자동으로 월·연 합계에 더해져요.
• 하루 마무리를 누르면 오늘 수익이 월·연 합계에 반영되고 일수익은 0원이 됩니다.
• 월수익·연수익을 직접 고쳐서 저장하면 그 값이 적용되고, 그 값부터 다시 자동 합산됩니다.
• 일·월·연 목표를 입력하면 오버레이에 달성률(%)이 표시됩니다. (비워두면 표시 안 함)
⚡ 빠른 수익 추가
• 버튼이나 직접 추가 금액을 누르면 일수익에 바로 더해지고 자동 백업됩니다.
⚠️ 초기화 (각 항목 0으로)
• 저장, 하루 마무리, 초기화 전에는 직전 값이 자동 백업됩니다.
• 월수익 초기화 시 오늘 수익도 함께 0이 됩니다.
• 연수익 초기화 시 일·월·연 수익이 모두 0이 됩니다.
현재 표시 — 일: 0원 / 월: 0원 / 연: 0원
목표 달성률 — 일: - / 월: - / 연: -
